# AGENTS.md

Правила для агентов и разработчиков, работающих с этим репозиторием.

## Код оркестратора меняется только в этом репозитории

- Единственное место разработки кода оркестратора — этот репозиторий (`agent-orchestrator`, ветка `main`, origin `git@github.com:alexander12356/agent-orchestrator.git`). Это касается `backend/`, `frontend/`, `worker/`, `scripts/` и корневых файлов.
- Копия оркестратора в Ubuntu WSL2 — среда запуска и тестирования, а не место разработки. Не править файлы под WSL напрямую: такие правки не попадут в репозиторий и будут потеряны при следующем обновлении.
- Порядок работы: правки → коммит и push в этот репозиторий → обновление копии в WSL2 из `main` → перезапуск оркестратора в WSL2 → проверка.
- Найденную в WSL2 проблему или правку нужно перенести в этот репозиторий, а не оставлять её только в среде запуска.
